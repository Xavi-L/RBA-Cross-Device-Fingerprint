# Android 5–7 App TLS 修复候选包

- APK：`HybridGuard-FeatureCollector-1.6.3-mtc-tls-debug.apk`
- 包名：`com.example.hybridguard.featureapp`
- 版本：`1.6.3-expanded-v2.2-mtc-tls` / `versionCode=10`
- 最低系统：Android 5.0 / API 21
- 构建日期：2026-09-18

## 本轮修改

API 21–25 的 App 上传、readiness、浏览器票据、阶段上报和配对查询使用系统信任加
官方 ISRG Root X1。证书校验和域名校验保持开启；API 26+ 使用原有系统默认信任。
不修改指纹字段、采集算法或配对协议。

证书/握手失败明确显示 `TLS_CERTIFICATE_ERROR` / `TLS_HANDSHAKE_ERROR` 并停止
自动重试。普通网络超时继续重试。后台上传现在会记录失败阶段、host、异常类型，
避免日志中只有 `Worker result RETRY`。失败的持久化 payload 不会被当作成功清除。

## 仍需注意的边界

此 APK 仍使用现有地址：

- 后端：`https://hemispheric-overmoist-candance.ngrok-free.dev`
- 页面：`https://xavi-l.github.io/RBA-Cross-Device-Fingerprint/`

APK 不能改变外部浏览器信任库。旧系统浏览器可能在页面加载或 API 上传时继续出现
证书错误；这种结果不能算完整采集成功。本次尚未有可配置证书的域名/服务器，
同域 HTTPS 部署模板及接入步骤位于 `deployment/legacy-android/`。

Android 5.1.1 全部失败只是用户提供的现象，尚无该版本日志确认原因。本轮以已经
提供的 Android 6.0 / 7.0 证书异常为依据，不声称修复全部旧系统失败。
