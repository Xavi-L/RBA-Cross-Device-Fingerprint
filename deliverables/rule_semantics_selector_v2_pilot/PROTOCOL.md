# 语义选择器 V2：一次六次拟合的内部试验

注册日期：2026-10-01。授权：本聊天用户“就按这个方案执行一轮试试”。本文件、CONTRACT.json、AUTHORIZATION.json 在首次真实拟合前写入；PRE_RUN_REVIEW.json 记录启动前检查。实际运行状态只看 RUN_STARTED.json 和 EXECUTION.json。

## 问题与范围

上一轮把语言首项条件加入候选池、用显式观测状态替换旧 webdriver 条件后，总检出持平，但两项新条件没有进入最终模型，屏幕与 webdriver 单项检出发生交换。旧选择器的名称排序和六条容量限制是保存轨迹中可见的因素。

本轮检验：在六条上限内消除显示名称的选择影响，并允许同信号组中满足训练非退化检查的语义质量替换，能否实际选入两项新条件，且保持整体及逐配置检出。此次比较不预设一定提高检出率。

固定使用上一轮已接入的 378 条 raw 记录：126 条干预、252 条成对对照，14 个配置、3 个环境、每个配置和环境 3 个重复。API29/30/36 三折留一环境，每折 252 训练、126 留出。样本成员、顺序、标签、折、支持阈值及约束逐项复用旧 CONTRACT.json。不加入历史 162 条或受阻的混合来源材料，不访问独立确认集。

这些是已暴露的模拟器内部开发材料。三个环境来自同一主机，且 API29/30 共用 WebView 主版本。留一环境结果不代表跨设备独立确认，也不估计真实正常 App 人群的误报率。

## 本轮算法

只训练 LANG_ADD_WD_REPLACE 候选池：保留旧语言长度家族，增加语言首项不一致；移除旧 webdriver 原子，加入显式观测状态原子。其余候选定义及训练编码方式不变。

1. `GREEDY_SEMANTIC_V2`：保留原目标函数、支持检查、前向增益、可行性检查和后向剪枝。遍历及最终平局以结构语义键排序，键包含字段、方向、参数、门控、极性，排除显示 ID；参数保持类型和操作数顺序。原数值比较项全部相等后，先比较注册质量，再比较结构键。重复结构键直接拒绝。
2. 注册质量只是限定在本轮两个正向新条件的偏好（1；普通或反向条件为 0），不是所有字段证据可靠性的通用排名。使用实际门控和语义描述识别条件，不以名称赋分。不越过支持、目标或可行性约束。
3. `R_KEEP_SWAP_V2` 从本折保存的新版稀疏模型初始化，不重新拟合编码器。增加候选仍执行原支持和可行性检查、保留训练攻击 T，且要求信号组覆盖 D 正增益。
4. 新增同信号组一换一：质量必须严格提高；逐条保留原模型已经检出的训练干预；不新增训练对照报警；不把原先明确的 T/F 变成 U/FAILED；遵守原支持、清洁预算、覆盖、家族限制、六条上限与复杂度上限。它可以在容量已满时发生。这里的非退化是相对当前模型的训练输出，不能保证留出集无退化，也不是相对旧 BASE 的训练保底。
5. 替换允许 D 下降，只要以上逐条输出检查全部通过。D 衡量信号组对干预的覆盖，可能把已经由另一组检出的样本重复计分；每次下降必须记录。普通增加仍要求 D 上升。
6. 候选操作先比较训练宏检出增益，再比较 D 增益、对照报警、最小覆盖、复杂度、质量及结构键。保存实际接受轨迹、拒绝计数和访问记录；不套用旧增加算法的解释作为新替换的完整拒绝原因。
7. 增加只会提高条数，替换只会将该条质量从 0 提到 1；同时记录已访问结构集合并设置最多 12 步，不允许循环或无限搜索。

原阈值：最少 3 个完整 triplet、2 个触发干预 triplet、1 个 bundle、1 个环境；各阶段覆盖至少 0.8；OP05 对照预算 0.05；至多 6 条、复杂度计数至多 12，以及原家族限制。

语言首项和语言列表长度是不同命题，不能普遍互换。替换被允许，只表示本折训练输出满足约束。webdriver 新条件区分 bool true/false、缺失、类型错误和观测矛盾；它报告采集到的属性状态，不能单独证明自动化事实。旧 `=== true` 谓词为 false 本身也不是错误语义。

## 执行与预算

- 共 6 次真实拟合：每折新版 GREEDY 一次，新版 R_KEEP 一次；只有 3 个最终 R_KEEP 各预测 126 条，总计 378 次新预测。
- 复用旧 BASE 和旧组合组已经保存的预测，基线新增拟合和预测均为 0。新任务全部关闭以后才由汇总器读取旧预测作比较。
- 从共享预算 189/200、剩余 11 次开始；全部完成后累计 195 次，剩余 5 次。每个 worker 最长 90 秒，6 个至多 540 秒。失败或超时按调用前持久化标记保守计数，保留异常；任何失败停止余下任务，不重试、不调参、不扩容。
- 拟合只打开训练输入和标签；模型保存并重新加载之后才打开本折留出输入；本折全部预测关闭之后才联结留出标签。冻结后不以结果修改模型或条件。
- 新目录保留合同、授权、源码副本、测试及审查记录、每次模型/训练轨迹/预测/调用计数/访问日志和报告。原产物保持不变。

## 预先确定的评估口径

同时报告相对 BASE 与旧组合组的变化：总体干预检出 n/N、三个环境各自的检出、14 个配置各自的检出、对照报警、明确输出覆盖、失败和未知、规则数及复杂度。逐条列出判定改变，不允许用总体持平隐藏某类退化。

另报告两项新条件在三折稀疏与最终模型中的入选情况、发生的替换、训练非退化检查与 D 变化。新条件没有入选或检出下降也是需要保留的结果。

相对 BASE 同时改变了候选池与选择器，只能解释为整体方案差异；相对旧组合组则是同候选池下的选择器差异。本次没有拆开语言与 webdriver 的单项贡献，不能把整体变化归因于某一项。

只有总检出不降、逐配置不降、对照报警不增加、明确输出不减少时，才可称本轮观察到相对相应参照无退化；否则明确记录退化并暂不建议直接替换。即使全部达到，也只构成内部开发结果。执行完即停止，下一轮需另行讨论；本轮不自动提交或推送。
