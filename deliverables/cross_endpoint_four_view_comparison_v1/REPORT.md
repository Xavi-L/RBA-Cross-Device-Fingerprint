# B3-A：固定小决策树的四视图实际开发比较

日期：2026-10-06。模式：`DEVELOPMENT_FOUR_VIEW_COMPARISON`。参考 HEAD：`2524fb7155313cfdfbe4180fc601622b3ec8379a`。

12 个预定模型均已实际拟合并预测。P0 中，双端直接拼接与追加 C1/C2 都检出 14/14 次有效干预，但小实验正常报警分别为 32/46 和 0/46。P1 留出旧先导时，追加关系把正常报警从 12/12 降为 0/12，检出均为 6/6。P2 留出匹配对照时，两种双端表示完全相同：检出 4/8，正常报警 6/34，关系没有额外收益。

这些是固定语言/时区视图的开发结果。两个小批次此前均已被研究过程接触，P1/P2 不是前瞻盲测；不同环境、ABI、App/Browser 版本与采集配方共同变化，无法唯一归因于一个版本。P0 高分依赖的关系、列表长度和固定取值有逐条反例，不能解释为识别任意操纵意图，也不能声称完整 paired244 方法或单端全部字段的性能上限。

## 1. 输入、学习流程与范围

准确字段来自现有字段合同，代码见 [features.py](features.py)，固定记录见 [PROTOCOL.md](PROTOCOL.md) 和 [SETTINGS.json](results/SETTINGS.json)。

| 视图 | 固定输入 |
|---|---|
| V_APP | App 侧语言/时区：Native locale、timezone ID、rawOffset；App Web language、languages 首项/长度、timezone_offset，共 7 个派生测量 |
| V_BROWSER | 独立 Browser Web language、languages 首项/长度、timezone_offset，共 4 个派生测量 |
| V_BOTH | 上述 11 个测量直接拼接 |
| V_BOTH_REL | 完全相同的 11 个测量，加原版 C1、C2 的独立 T/F/U 编码 |

两端 Web 使用同一有限标签解析。没有加入列表尾项、整列表类别/hash、额外跨端公式、C3、D1/D2。Native rawOffset 保留原符号和不含 DST 的语义，Web 偏移保留 UTC-local 方向。V_BOTH 已包含 C1/C2 的全部操作数，小树可以通过多个分支隐式利用关系；最后两个视图才是相同信息来源、学习器和容量约束下的显式表示比较。

同一方案只 fit 一份原字段变换，类别词表和数值中位数只看训练成员；V_BOTH_REL 只追加固定 F/T/U 的 6 列。未见类别编码全零并记明原因，不扩充词表。每个数值都带缺失指示，训练整列无值时使用明确的计算占位。填补不回写观测。所需端点/绑定失败为 FAILED，所需视图全部无有效测量为 U；单端推理不读取另一端。来源、标签、家族只参与权重或评价，ID、场景、版本、时间、路径、设备信息与未来恢复均不进入树。

固定参数为 `gini / best / max_depth=3 / min_samples_leaf=2 / random_state=20261006 / class_weight=None`；其余实际默认值已保存。正类概率由 `classes_` 定位，按 `>=0.5` 报警，没有评价集阈值选择。实际 Python 3.13.5、scikit-learn 1.7.2。检查未找到已有可用 sklearn 后，新建隔离环境，没有升级旧环境。依据为 [DecisionTreeClassifier 官方 API](https://scikit-learn.org/1.7/modules/generated/sklearn.tree.DecisionTreeClassifier.html)；自有透明预处理代码执行固定的独热/中位数规则，没有调用自动搜索。

|---|---|---|---|
| P0 | 630+18+42=690；676 正常/14 有效干预 | 无；144/117 历史正常评价分开 | 四家族各 1/8；三个正常来源各 1/6，再各自均分记录 |
