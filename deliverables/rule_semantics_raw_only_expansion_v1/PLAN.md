# Raw-only 跨环境扩展：采集前登记

本轮先补环境与配置覆盖，再冻结新旧候选池的同数据比较。复用 FeatureApp code 12、原攻击工具和冻结参数。历史 162 条仍是单独的已暴露开发参照，不接入新 raw-only 训练。

已发现 API 28 / WebView 66 的基线缺少 webdriver API，且 stealth 语言插件因 Object.fromEntries 缺失而失败。保留其 31 个原计划位置：23 次已采集、1 次失败、7 次未尝试。该环境不能当作本轮“布尔 webdriver 可观测且工具兼容”主比较的第三环境，也不能将 U 改成 F。它作为单独的兼容性边界结果报告；没有撤销或替换原尝试。

新增 Google 官方 API 30 ARM 镜像，选择依据为不同 Android 版本及更晚系统镜像；具体 WebView 版本与可用性由启动后的单次冒烟读取确认。若不满足适用条件，保留失败并重新报告，不因检测效果不佳换环境。已有 API 29、API 36 与新 API 30 为拟议主比较环境；全部属于同一 Mac 上的模拟器开发材料，不是独立真机、确认集或总体正常 App 样本。

每个拟议主环境保留原来的两配置最小采集（31 次：18 个三联监督角色位置 + 13 个辅助位置）。随后在相同安装上补其余 12 个历史配置，每个配置 3 轮 clean_pre → attack → clean_post，即 108 次，另外 1 次恢复环境后的冒烟。每个环境合计 140 次，三个环境拟议 420 次，其中 378 条监督角色候选（126 个指定干预位置，252 个配对无该干预对照）和 42 个辅助位置。

全部 14 个配置及其实际执行入口、参数、声明字段保存在 CONFIGURATIONS.json，与历史162的 config_id 集合逐一对应。Selenium 不在历史已准入14配置中。时区/屏幕使用原 CDP emulation runner；其余使用原 week6 runner。仅在本仓库增加编排与分析，不修改攻击侧仓库。独立依赖目录复用固定版本并补 Playwright 1.61.1，禁用安装脚本及浏览器下载。

每个采集位置仅一次尝试；失败则停止该环境当前 campaign，保留原计划的未执行位置，不自动重试。API、原始值、状态与类型缺失均保留 U/FAILED。训练标签只依赖声明干预的执行、效果和撤销证据，不依赖候选条件或检测器是否报警。必须核对各配置声明字段的活跃值及前后恢复；不把无字段变化的工具名字当作成功干预。

未来主比较计划：BASE 与 LANG_ADD_WD_REPLACE；两组均从同池 GREEDY 初始化后用原 R_KEEP_V1；三个环境整组留一，完整 bundle/triplet 不拆分。最少支持量、80% 分阶段决策覆盖率、OP05 clean 报警预算及原复杂度保持不变。3折 × 2候选池 × 2拟合阶段 = 12 次 fit；先读取并核对当前预算，避免为两配置小样本先消耗一轮 fit。数值阈值只在本折训练侧学习，不调参追赶旧历史分数。

当前仅采集与准备，不以这份采集计划替代最终准确成员、分割和执行合同。全部主环境配置齐备、效果/恢复与输入检查通过后才登记具体成员与训练任务。若完整比较仍受兼容性或覆盖约束阻碍，报告原因；不静默删除失败配置/环境，也不将局部成功写成整体完成。
