# 第二环境 raw-only 最小验证

本轮在新的 Android 10 / API 29 模拟器数据目录上复用 code 12 采集 APK、既有攻击工具和冻结的 31 次采集流程。实际 Android / WebView 版本以启动后的读取结果为准。已有 API 36 环境作为开发期对照，不能视为独立确认集。

每个环境：冒烟 1 次；无攻击时间对照 3 组三联样本（9 次）；CDP 连接/导航对照 1 组（3 次）；webdriver 干预和 languages 干预各 3 组三联样本（各 9 次）。三联样本是 clean_pre → attack/control_mid → clean_post。CDP 对照并不覆盖 Puppeteer 的所有内部行为。

先通过冒烟，再运行剩余 30 次；每个步骤只尝试一次，失败保留并停止。缺失、异常和未知状态均如实保留。运行结束后只做字段语义、干预效果/恢复、来源绑定、分组与支持量检查。

若两环境各完成 31 次，总计 62 次采集，其中 36 条有监督角色的候选输入（12 次指定干预 + 24 次配对无该干预对照），另外 26 条仅辅助检查。干预角色不等于普遍恶意/正常标签。

历史 162 条保持独立；不将旧的 webdriver false 补成 raw false；不降低既有质量、覆盖率和误报预算门槛；本轮不调用 fit/predict、不启动正式重训、不消耗训练次数预算。只覆盖两个干预配置，不能报告整个检测器的检出率提升，也不能估计正常真机 App 的总体误报率。

采集接收器仅监听本机 8000 端口、单 worker、独立数据目录。所有模拟器数据文件写入忽略的 runtime 目录；原始采集、失败日志和回执保留在 runs 目录。攻击侧仓库不做修改。
