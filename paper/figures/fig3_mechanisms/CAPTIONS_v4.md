# Figure 3 v4 — How contextual references contribute

## English

Illustrative mechanisms on valid, applicable observations. (a) With Native memory of 4 GiB and a Web report of 8 GiB, the report does not exceed the fixed 8 GiB comparator but violates the Native-derived 4 GiB upper envelope. (b) Each horizontal row follows one source from Before to After, using normalized UTC offsets. A system timezone change moves Native and Web from UTC+8 to UTC+9 together; a Web-only edit leaves Native at UTC+8 and changes Web to UTC+9. The right-hand bracket compares the two After offsets. Arrows illustrate changes; consistency is checked between the two surfaces within each observation, without requiring a historical Before input. These values are schematic examples, not additional measured records. (c) A reported viewport dimension P, converted to the comparison unit, violates the Host bound when P exceeds H plus tolerance epsilon. The aligned left edges emphasize dimension rather than position. This is a comparison of reported dimensions, not a depiction of visible content overflowing a phone screen. Geometry remains a standalone study; quantitative results are reported separately.
