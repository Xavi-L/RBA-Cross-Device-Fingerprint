# Figure 3 — How contextual references contribute

## English

Illustrative mechanisms on valid, applicable observations. (a) With Native memory of 4 GiB and a Web report of 8 GiB, the report does not exceed the fixed 8 GiB comparator but violates the Native-derived 4 GiB upper envelope. These values are a schematic example, not additional experimental records. (b) After converting offsets to the same sign convention, a legitimate system change can move both Native and Web offsets from a to b; a Web-only edit leaves the Native reference unchanged and creates a mismatch. Distinct a and b illustrate the contrast rather than measured traces. (c) A reported viewport dimension P, converted to the comparison unit, violates the Host bound when P exceeds H plus tolerance epsilon. The aligned left edges emphasize dimension rather than position. Geometry remains a standalone study; quantitative results are reported separately.

## 中文

有效且适用观测上的机制示意。(a) 当 Native 内存为 4 GiB、Web 报告为 8 GiB 时，Web 报告未超过固定的 8 GiB 比较器，却超过由 Native 推导的 4 GiB 上界；这些数值是说明性示例，并非新增实验记录。(b) 统一时区偏移符号后，正常系统变化可使 Native 与 Web 从 a 共同变化到 b，而仅修改 Web 时 Native 参照保持不变，从而产生不一致。不同的 a、b 用于概念说明，不是测量轨迹。(c) Web 视口经单位转换后的尺寸 P 超过 Host 尺寸 H 与容差之和时触发检查；两个框左侧对齐，以强调尺寸比较而非位置偏移。几何仍是独立专项，定量结果另行报告。
