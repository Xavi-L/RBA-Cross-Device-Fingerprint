# Original SVG assets for Figure 2

These are unchanged SVG files extracted on 2026-10-23 from the project's existing
[`HybridGuard_Color_Assets_v2_20261022.zip`](../../../visual_assets/color_v2_20261022/HybridGuard_Color_Assets_v2_20261022.zip).
The archive is the source used by `HybridGuard_Color_Assets_Catalog_v2_20261022.html`.
SHA-256 values were checked against its `manifest.json` during extraction.
The original bytes are retained here; figure placement, scaling, and internal-ID
namespacing are performed by `../build_figure.py` when assembling the final SVG.

`source_manifest.json` records each asset's original source URL, archive path,
license note, checksum, and local path. It also records the archive's Git blob ID
and SHA-256. All nine brand files and seven technical icons are selected for this figure.
The final figure's `../SOURCE_MAP.json` identifies their placements.
