# Overview 图注

## English

Complementary observation surfaces for cross-checking Android environment reports. The solid blue Native–App Web edge denotes memory and timezone consistency relations used by the current detector. Host–web geometry is implemented and evaluated separately, outside the current Full App detector and its candidate pool. The dotted Native–Host edge denotes shared context only, not an independent detection rule. Open arrowheads indicate comparisons, not communication paths or mutual authentication. Association within the same App execution does not imply atomic sampling, and no surface is trusted ground truth. Single-view checks, the optional linked Browser, and the complete decision process appear in the system-design figure.

## 中文

对 Android 环境报告进行交叉核验的互补观测面。蓝色 Native–App Web 实线表示当前检测器采用的内存和时区一致性关系。Host–web 几何已实现并接受独立评估，但未纳入当前 Full App 检测器及其候选池。Native–Host 点线仅表示共享上下文，不代表独立检测规则。开放式箭头表示比较关系，不表示通信路径或相互认证。同一次 App 执行中的关联不意味着原子同步采样，任何观测面都不是可信真值。单视图检查、可选的关联 Browser 和完整判定流程见 system design 图。

## 使用说明

将 system-design figure 替换为正文中的交叉引用。图号由最终编排确定。蓝边、赭色虚线和灰色点线的地位不同；保留图注中的关系范围。
