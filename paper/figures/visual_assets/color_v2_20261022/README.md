# HybridGuard — curated full-color figure assets v2 (2026-10-22)

**Purpose:** source palette for paper graphics. This is a candidate set, not a claim that every depicted app or browser was empirically evaluated.

- Full package: `HybridGuard_Color_Assets_v2_20261022.zip`. Contains editable SVGs, original rasters where applicable, preview PNGs, searchable HTML catalog, manifest, and source/license notices.
- Preview boards: `HybridGuard_Color_Assets_Brands_v2_20261022.png` and `HybridGuard_Color_Assets_Icons_v2_20261022.png`.
- Candidate set: branded apps/browsers plus multi-color technical icons (clock, globe, hardware, filter, database, documents, warning, success, failure, unknown).
- Keep trademark logos in original brand colors; no generic black-outline replacements.
- Warning/error/unknown/pass have different **shape as well as color**. A green check on a condition does not imply device authenticity.
- The upstream assets and license notices are bundled. Respect their terms and use logos only to refer to actual applicable products or explicitly labeled illustrative categories.

This is a visual asset library, not a publication-ready method diagram.
