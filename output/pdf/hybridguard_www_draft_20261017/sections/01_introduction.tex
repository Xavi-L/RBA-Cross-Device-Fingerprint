\section{Introduction}
Web services use browser-visible environment reports to recognize clients and inform security-related decisions, including authentication~\cite{laperdrix2020browser,alaca2016device,spooren2015harmful}. A party controlling the reporting surface can alter these reports without changing the underlying device. Fingerprint spoofing and inconsistent evasive reports are established concerns~\cite{liu2022gummy,vastel2018fpscanner,venugopalan2025fpinconsistent}. Their integrity therefore matters to these security decisions.

In Android hybrid Web applications, Android Native observations describe system and hardware properties; the WebView Host supplies container, configuration, and layout context; and App Web exposes JavaScript-visible reports. These partially overlapping observations concern the same running environment, with complementary meanings~\cite{android2026webview}. A Web value that appears reasonable in isolation may be incompatible with its system or container context. We ask: \emph{When can cross-layer semantic consistency serve as integrity evidence for Web-visible environment reports?}

Web-reported memory can remain below a global threshold yet exceed what the device plausibly supports; a Native reference supplies device context. A normal system timezone change can preserve compatible observations, whereas changing only the Web report may break their relationship. Normal container-layout changes can affect Web geometry; Host context helps interpret whether a reported size remains compatible with its container. These interpretations depend on measurement semantics, legitimate setting changes, and available evidence.

\hg associates observations from the same hybrid Web execution and evaluates semantic relations with explicit applicability conditions. Controlled fingerprint manipulations provide the experimental setting: they reveal when local report changes leave contradictions and how normal environmental changes affect the same relations.

The evaluated App detector (\full), which combines within-view and cross-view checks, detects 105/126 effective modifications (83.3\%) across 14 controlled configurations, with no alarms on 252 controlled normal records. Separate comparisons of fixed checks explain the value of references: a Native memory reference supplies device-specific context, and the Native timezone reference distinguishes tested system changes from local report modifications. A separate Host geometry study distinguishes tested layout changes from report modifications using a container reference; this check is not integrated into \full. These comparisons suggest that cross-layer references are useful when they remain observable and semantically informative beyond the locally modified Web report.

Historical normal records expose normal-alarm and evidence-availability costs beyond the controlled benchmark. An optional external Browser extension examines evidence from a separate Web execution on the same device.

Our contributions are:
\begin{itemize}[leftmargin=*,itemsep=1pt,topsep=2pt]
\item A formulation and implemented framework for assessing report integrity through semantic relationships among complementary observations from the same hybrid Web execution.
\item Experimental evidence showing how Native references add device context and distinguish local manipulation from normal changes, complemented by a standalone study of Host geometry.
\item A characterization of detection capability, normal alarms, and unavailable evidence that identifies applicability conditions and costs.
\end{itemize}
