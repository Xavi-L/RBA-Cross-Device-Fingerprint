\section{Conclusion}\label{sec:7}}

HybridGuard uses associated Android observations to assess the compatibility of Web environment reports. Integrated App detects 105/126 controlled modifications with no alarms on 252 normal positions; separately refitted Web-only and no-memory alternatives each detect 96/126, with all nine differences in the CPU-plus-memory recipe. Separate timezone and Host geometry studies distinguish selected edits from legitimate variation. Historical records and the Browser extension expose alarm and availability costs. The released dataset supports further analysis of retained measurements, label provenance, and missing evidence. Together, these results motivate evaluating report-integrity checks by applicability, detection, normal alarms, and definite outputs within the tested reference domains.
