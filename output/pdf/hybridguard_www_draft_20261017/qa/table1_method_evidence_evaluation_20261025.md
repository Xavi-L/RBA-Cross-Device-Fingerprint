## Why the columns are complementary

- Research focus identifies the question; Method identifies the technique used to address it.
- Observation surfaces identify where observations originate; Evidence identifies the particular signals or relationships examined.
- Evaluation identifies the actual data or experimental setup used to validate the work, instead of repeating its intended application or output label.

The cells select a distinctive aspect of each study. They do not enumerate every check, signal, or experiment. For example, FP-Scanner also examines fonts, APIs, and canvas, while HybridGuard includes within-view as well as cross-view relations.

## Primary-source evidence

### FP-Scanner — ref04

[USENIX paper](https://www.usenix.org/system/files/conference/usenixsecurity18/sec18-vastel.pdf), §3, printed pp.138–141: heuristic consistency checks grouped by OS, browser, device, and canvas. §3.1, p.139 compares JavaScript `navigator.userAgent` with the HTTP `User-Agent`. §4.2.1–4.2.2 and Table 8, pp.143–144 evaluate fingerprints collected with and without fingerprinting countermeasures across browsers, virtual machines, and smartphones. Thus Countermeasure trials describes experiments actually conducted.

### Picasso — ref05

[Author's paper](https://elie.net/static/files/picasso-lightweight-device-class-fingerprinting-for-web-clients/picasso-lightweight-device-class-fingerprinting-for-web-clients-paper.pdf), §3.1–3.2, PDF pp.2–3: seeded canvas challenges, client rendering and hash responses, and server verification. §5, PDF p.8 reports a two-week Google deployment with challenges sent to 52 million clients; §5.2 analyzes observed login attacks. Live traffic deployment describes this evaluation, rather than proposed marketplace applications. No deployment accuracy percentage is asserted in the table.

### FP-Inconsistent — ref06

[Author manuscript](https://hariv.github.io/files/fpinconsistent.pdf), §7.1–7.2, PDF pp.10–11: data-driven discovery of inconsistent attribute combinations and changes across requests associated by cookie/IP. §7.3–7.4, p.11 evaluates rules on purchased bot traffic and university users' traffic; §7.5 additionally tests privacy tools. Bot and human traffic describes these actual evaluation populations.

The accessible manuscript is arXiv v2 dated 2025-01-31. The ACM final DOI returned HTTP 403. The [author's IMC 2025 listing](https://www.shaoormunir.com/tags/Fingerprinting) corroborates the core method and purchased-bot setting. The table uses facts supported by the public manuscript and avoids version-sensitive sample sizes or results; the ACM typeset final was not inspected.

### BrowserFM — ref07

[MADWeb paper](https://madweb.work/papers/2025/madweb25-huyghe.pdf), §IV–IV-A, PDF pp.4–5: feature models represent fingerprints, environments, and browser configurations, linking configuration choices to attributes. Fingerprints are actively generated across Chromium versions/configurations, including headless/headful. §VI, pp.7–8 evaluates configuration-flag identification and attribute subsets with samples generated on a second machine. Chromium configurations therefore describes controlled evaluation inputs, not an assumed live-bot deployment.

### WVProfiler — ref08

[arXiv paper](https://arxiv.org/pdf/2208.01968), §3, PDF p.4: Frida instrumentation of WebView/WebViewClient methods records user agents, custom headers, and URLs. §4, pp.4–5 begins with over 20,000 AndroZoo apps, identifies 5,145 that call WebView APIs, and additionally analyzes ten popular apps automatically and manually. AndroZoo app sample identifies the sampled corpus without conflating the starting sample with successful executions. Headers includes user-agent headers.

### Tracking Without Borders — ref09

[PoPETs paper](https://petsymposium.org/popets/2025/popets-2025-0155.pdf), §4–4.2.2, printed pp.748–750: static analysis identifies WebView implementations/configurations and attribution; dynamic analysis combines Frida, API/JavaScript activity, and network traffic. §4.2, p.749 describes five-minute executions using six regional network exits (Europe, US, India, Brazil, Japan, Australia) and corresponding GPS locations. Six-region app runs refers to those actual execution conditions, rather than six physical-device deployments.

### Cross-Boundary Mobile Tracking — ref10

[NDSS paper](https://www.ndss-symposium.org/wp-content/uploads/2026-s910-paper.pdf), §IV, PDF pp.4–7: WebViewTracer correlates Java method calls with VisibleV8 JavaScript execution to identify injection and exfiltration. §V, p.7 describes automated runtime crawls of a popularity-stratified AndroZoo sample on instrumented Android devices. Table III distinguishes 10,000 initial apps from 4,597 that actually loaded a WebView. Additional manual checks examine identification heuristics and crawl coverage. Instrumented app crawls accurately states the validation method without collapsing these denominators.

### HybridGuard

Current manuscript §2.2 and §3.2–3.3 define conditional semantic relations and cross-view consistency evidence. §4 and §5 evaluate effective controlled report edits and benign changes. The pre-existing footnotes retain the separate Host-geometry evaluation and optional linked-Browser scope.
