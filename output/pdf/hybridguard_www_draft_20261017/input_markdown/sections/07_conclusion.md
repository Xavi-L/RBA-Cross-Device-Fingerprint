# 7 Conclusion

HybridGuard uses associated Android observations to assess the compatibility of Web environment reports. On the controlled App benchmark, Integrated App detects 105/126 effective modifications with no alarms on 252 normal record positions. Its separately refitted Web-only and no-memory alternatives each detect 96/126; all nine differences occur in the CPU-plus-memory recipe. Exploratory timezone and Host geometry comparisons show how contextual references can distinguish selected edits from legitimate variation. Historical normals and the optional Browser extension expose the accompanying alarm and availability costs. These results support evaluating report-integrity checks jointly by applicability, modification coverage, normal alarms, and definite outputs, within the limits of the references and predicates tested.
