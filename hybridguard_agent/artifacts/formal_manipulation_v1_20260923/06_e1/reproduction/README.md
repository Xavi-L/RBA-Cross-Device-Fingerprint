# S06 执行与复核说明

这四份脚本仅编排、只读导出或核对本次结果，不是新检测实现。算法全部来自 JOB_BINDING 指定的 S05-R 冻结字节。

1. materialize_s06.py 在本次授权下校验冻结、复制临时运行根并生成新 runnable job；静态计划不直接执行。
2. execute_s06.py 分别启动 predict/evaluate 两个独立解释器阶段，使用 profile/IO 审计边界；真实调用命令、cwd、起止时间和退出码已保存在 PREDICT_SUBPROCESS.json 与 EVALUATE_SUBPROCESS.json。
3. report_saved_s06.py 仅连接已保存的事件和评估长表，输出逐配置/逐单元诊断，不导入检测器。
4. check_saved_s06.py 仅读取关闭产物及冻结分母核对完整性、绑定、分母、关联、边界和旧文件不变性，不执行算法。

现有预测已完成一次。脚本和命令是复现记录，不构成重新运行授权；非空输出及已有结果不会用于选优覆盖。未来若需技术复现须另获授权、另设 run/output，并重新由原 r1 快照建立临时运行副本。当前绝对临时模块路径是本次真实执行证据，临时目录未来可能被系统清理；不可回退工作区代码。

静态历史授权标记保持原样。研究数据和评估事实的实际绝对路径在 JOB_BINDING/进程审计中。不得将独立评估长表送回预测 worker。后续研究步骤尚未获本次授权。

保存文件核对曾修正 ALERT 简称为正式 MANIPULATION_ALERT 枚举；初次核对记录在 audit_history 中，原始预测及冻结评估产物无变化。
