# HybridGuard ACM Working Draft - Two-Track Evaluation Revision

Main document: `hybridguard_draft.tex`

This revision explicitly separates two controlled App177 evaluation tracks:

1. Attack-side 100-run stability campaign (effect-positive active runs; attack-side frozen evaluator).
2. Main-repository 69-pair baseline->attack-active re-evaluation (main-repository evaluator catalogs).

The two tracks use different statistical units and evaluator versions; their counts are not pooled or interpreted as one detection rate. Browser67/paired244 detection-gain claims remain future work.
