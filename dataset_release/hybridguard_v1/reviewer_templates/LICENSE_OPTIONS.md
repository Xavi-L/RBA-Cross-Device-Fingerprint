# License selection — no license applied

The project lead has confirmed public release authorization for every included source. A dataset reuse license has not yet been selected. This file recommends options for an explicit decision; it does not apply either option, waive rights or grant additional rights. The archive must not be described as already CC BY or CC0 licensed.

| Option | Practical effect if explicitly selected | Decision needed |
|---|---|---|
| CC BY 4.0 — recommended when attribution is desired | Permits sharing and adaptation, including commercial uses, subject to attribution, a license link and notice of changes | Confirm these reuse permissions and the attribution statement, including wording during anonymous review |
| CC0 1.0 — alternative | Seeks a worldwide waiver of copyright and related rights to the extent legally possible, without an attribution condition | Confirm that the project intends this broader waiver |

Official reference texts: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) and [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Neither option itself removes privacy or other rights that may apply. These links are references, not license notices for this dataset.

The bundled loading and validation scripts require a separate check of applicable software-license coverage; selecting a data license does not automatically license software. No additional code license is granted here. Once a choice is confirmed, update the license statement and machine-readable manifest consistently before final platform publication. Until then, record `PENDING_SELECTION` instead of inventing a license identifier.
